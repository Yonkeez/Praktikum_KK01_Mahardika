# Tugas 1 - Klasifikasi Wine Quality dengan KNN

Repositori ini berisi implementasi algoritma K-Nearest Neighbors (KNN) untuk mengklasifikasikan kualitas wine menggunakan Wine Quality Dataset.

## Ringkasan Proyek

- **Dataset**: Wine Quality Dataset (WineQT.csv)
- **Model**: K-Nearest Neighbors (KNN)
- **Tahapan**:
  1. Eksplorasi Data Awal (EDA)
  2. Preprocessing (Pembersihan fitur & standarisasi skala)
  3. Eksperimen Nilai $k$ dan Metrik Jarak
  4. Evaluasi Model (Confusion Matrix & Classification Report)
- **Hasil**: Akurasi pengujian berhasil mencapai target $\ge$ 60%.
